# Plantillas de pedidos cortos

Fórmulas que consiguen respuestas útiles y breves. Reemplaza lo que va entre [corchetes].

## Resumir
```
Resume [el texto] en [5] viñetas. Máximo [80] palabras.
```

## Editar un texto
```
Corrige ortografía y claridad. Devuelve solo las frases cambiadas.
```

## Arreglar código
```
Error: [mensaje]. Muestra solo la función corregida y una línea explicando la causa.
```

## Redactar
```
Escribe un [correo/mensaje] para [destinatario] sobre [tema]. Tono [formal/cercano]. Máximo [120] palabras.
```

## Decidir entre opciones
```
¿[Opción A] o [Opción B] para [objetivo]? Recomienda una y da 3 razones.
```

## Continuar en un chat nuevo
```
Contexto: [pega el resumen del chat anterior].
Sigamos con: [siguiente paso].
```

## Cerrar un chat largo
```
Resume en 10 líneas lo decidido y lo pendiente, para continuar en otro chat.
```
